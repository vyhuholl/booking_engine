# Service layer

Здесь находится бизнес-логика. Handler вызывает service, service вызывает repository.

Правила:
- Никакого SQL и pgx в этом слое
- Вся бизнес-логика (валидация, проверка ролей, пересечения) — здесь
- Ошибки — доменные (ErrConflict, ErrNotFound), не SQL-ошибки
- Каждый публичный метод принимает context.Context первым аргументом
- Новый метод = новые тесты в *_test.go рядом
