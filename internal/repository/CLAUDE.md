# Repository layer

SQL-запросы через pgx. Никакой бизнес-логики.

Правила:
- Методы принимают context.Context и конкретные параметры (не структуры запроса)
- Возвращают доменные модели из internal/model
- SQL-ошибки транслировать в доменные (pgconn.PgError → ErrConflict и т.д.)
- Все запросы — параметризованные ($1, $2), никакого fmt.Sprintf
- timestamptz для всех временных полей
